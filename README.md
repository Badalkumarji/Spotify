# 🎵 Spotify Clone

A front-end music streaming web application inspired by Spotify, built using **HTML**, **CSS**, and **JavaScript**. This project simulates the user interface and core playback functionalities of the original Spotify platform and is designed to showcase responsive design, DOM manipulation, and interactive features using vanilla JavaScript.

---

## 📌 Project Overview

This clone replicates primary Spotify features such as:
- A responsive sidebar with **Home**, **Search**, and **Your Library** options
- A list of songs with individual **Play/Pause** functionality
- A **footer playback bar** with controls like next, previous, volume, and a seek/progress bar
- **Real-time search** functionality to filter songs
- An **About Us** page detailing features of the original Spotify

> ⚠️ Note: This is a front-end-only project with no backend integration.

---

## 🔑 Key Features

- 🎧 **Audio Playback**: Play/pause, next/previous track, and progress control.
- 🔍 **Live Search**: Dynamically filters songs as you type.
- 📱 **Responsive Design**: Mobile-friendly layout using media queries.
- 📜 **About Us Page**: Additional details about Spotify and its services.
- 🎨 **Styled Interface**: Clean Spotify-like theme using CSS Flexbox and hover effects.

---

## 🛠️ Technologies Used

### 🔹 HTML
- Page structure with `<nav>`, `<div>`, and semantic tags
- Embedded scripts and linked CSS for modularity

### 🔹 CSS
- Custom themes and responsive layout with Flexbox
- `@media` queries for cross-device compatibility
- Button and hover transitions for user interactivity

### 🔹 JavaScript
- `Audio()` object for song playback
- Event listeners for search, navigation, and media controls
- Dynamic DOM manipulation for a seamless UX
